🎨 EmbeddedResizable System

Sistema avançado de mídia interativa para Next Level Editor

📖 O que é?

O EmbeddedResizable é um sistema completo que permite inserir e manipular conteúdo multimídia (imagens, vídeos, anexos) de forma profissional e intuitiva no editor.

Todo conteúdo inserido é automaticamente encapsulado em containers interativos que podem ser redimensionados, arrastados e alinhados com apenas alguns cliques ou teclas.

💻 Exemplo de Uso

Inserindo uma imagem com o sistema EmbeddedResizable:

// Importar a função utilitária import { insertEmbeddedResizable } from '@/utils/embeddedResizable' // Inserir imagem redimensionável insertEmbeddedResizable({ type: 'image', src: 'https://example.com/photo.jpg', alt: 'Beautiful landscape', width: 600, height: 400, maintainAspectRatio: true, alignment: 'center' }) // Inserir vídeo do YouTube insertEmbeddedResizable({ type: 'embed', src: '<iframe src="..."></iframe>', width: 640, height: 360, maintainAspectRatio: true, alignment: 'center' })

⌨️ Atalhos de Teclado

Controle total via teclado para uma experiência profissional:

Atalho Ação
Click Selecionar conteúdo
Shift + ← / → Redimensionar largura (±10px)
Shift + ↑ / ↓ Redimensionar altura (±10px)
Delete ou Backspace Remover conteúdo (com confirmação)
Escape Desselecionar conteúdo
Tab Navegar entre elementos
