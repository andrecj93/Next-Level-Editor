📖 Como Usar

  • Digite {{ no editor para abrir o autocomplete de variáveis
  • Use ↑ e ↓ para navegar pelas variáveis
  • Pressione Enter ou Tab para inserir a variável selecionada
  • Pressione Esc para fechar o autocomplete
  • As variáveis aparecem com estilo visual destacado (pill/badge)
  • Passe o mouse sobre uma variável para ver sua descrição
